# 简核工具 · 订单差异检查

中文离线 CSV 订单比较样品。按订单号匹配两份表，检查缺单和一个字段的文本差异，并导出差异 CSV。

创作者主页：[简核工具 · 爱发电](https://ifdian.net/a/jianhe-tools)。公开样品免费查看和体验，自愿赞助不包含定制开发或持续服务承诺。

## 使用

下载仓库 ZIP 并解压，用 Edge 或 Chrome 打开 index.html。先点“载入演示订单”，再点“检查差异”。可以选择自己的 UTF-8、逗号分隔 CSV，分别指定订单号列和比较字段。

程序无服务器、第三方依赖或上传接口；数据在浏览器内存中处理，不修改原文件。只导出检查结果。

## 当前范围

- 独立的列名映射、文本比较、缺单、空格选项。
- 空订单号和重复订单号会停止检查，避免隐式覆盖。
- 单文件最多 5 MB，页面显示最多 1000 条，导出完整差异。
- 支持 CSV 引号、逗号和单元格换行；导出会保护公式前缀。

不支持直接导入 xlsx、金额归一化、多行订单聚合、退款拆单或多字段比较。不判断财务正确性。CSV 导入时应按文本保留订单号，避免 Excel 自动转换前导零等标识。
